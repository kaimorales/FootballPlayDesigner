🏈 Football Play Designer
1st Place – Claude AI Hackathon @ Pitt

A simple, fully customizable web app that lets football coaches design, plan, and save offensive plays. Includes built-in defensive coverages for more dynamic game planning. Designed to make advanced play design more accessible for lower-budget high school programs.

🚀 Features

Draw and customize routes

Move any player on the field

Built-in defensive coverages (Cover 1, Cover 2, Cover 3)

Save and load plays

Export plays as images
